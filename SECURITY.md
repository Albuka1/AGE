# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |

## Reporting a Vulnerability

Report privately via GitHub Security Advisories:
https://github.com/Albuka1/Age/security/advisories/new
Or email: Albuka1@users.noreply.github.com

Response within 72 hours. Patch released as soon as possible.

## Scope

In scope: path traversal, sandbox bypass, memory safety in ECS, GL/AL misuse.
Out of scope: dependency issues, user misconfiguration.
